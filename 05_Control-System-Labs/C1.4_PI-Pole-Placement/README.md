# C1.4 · DC Motor PI Control Design by Pole Placement from an LLS Model

> **DC Motor Control System Labs** · ⏱ 1 hour · 🧰 Hardware: ACE-Lab Base + Sense + Actuate

Identify the motor with linear least squares, calculate PI gains by pole placement, and verify the designs on the hardware.
