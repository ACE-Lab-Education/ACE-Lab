## Getting started
1. **Download this repository:** click the green **Code** button, then **Download ZIP** (or `git clone https://github.com/ACE-Lab-Education/ACE-Lab.git`).
2. Set up the software: **G1** [Install MATLAB, Simulink and Code Generation](https://github.com/ACE-Lab-Education/ACE-Lab/tree/main/01_Getting-Started/G1_Install-MATLAB-Simulink), then the free **G2** [MATLAB Onramp](https://github.com/ACE-Lab-Education/ACE-Lab/tree/main/01_Getting-Started/G2_MATLAB-Onramp) ([Course](https://matlabacademy.mathworks.com/details/matlab-onramp/gettingstarted)) and **G3** [Simulink Onramp](https://github.com/ACE-Lab-Education/ACE-Lab/tree/main/01_Getting-Started/G3_Simulink-Onramp) ([Course](https://matlabacademy.mathworks.com/details/simulink-onramp/simulink)).
3. Pick an **ACE-CORE** guide below and read the theory.
4. Do its supporting **ACE-Lab** exercises: follow the exercise sheet and run the model from the exercise's `simulink/` folder.

**Hardware:** P (Preliminary) and M (Measurement) exercises use ACE-Lab **Base + Sense**. A (Actuator) and C (Control System) exercises also need ACE-Lab **Actuate**. MATLAB & Simulink files for the DC motor exercises (A1.4–A1.5, C1.4–C1.6) are in **[Code_DC-Motor](Code_DC-Motor)**.

ACE-CORE is the theory behind ACE-Lab: **C**omprehend, **O**perate, **R**efine, **E**ngineer. Click a guide to open it. Each guide lists the ACE-Lab practical exercises that support it, with their exercise sheets.
