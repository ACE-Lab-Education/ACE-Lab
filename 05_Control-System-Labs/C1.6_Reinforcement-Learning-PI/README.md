# C1.6 · DC Motor PI Tuning using Reinforcement Learning

**DC Motor Control System Labs** · ⏱ 1 hour · 🧰 Hardware: ACE-Lab Base + Sense + Actuate

Train a TD3 agent in simulation to choose the PI gains every 3 s, and evaluate it against the requirements when the motor changes.
